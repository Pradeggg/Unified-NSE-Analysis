## Editorial Rules

- State the report date and data timestamp whenever available.
- Separate reported facts, model outputs, analyst views, and assumptions.
- Use “watchpoint”, “risk”, “invalidation”, or “scenario” instead of directive language.
- Never imply assured, fixed, or guaranteed returns.
- Include the public report link in outbound messages.
- Keep the full disclaimer intact; do not shorten it for public distribution.
