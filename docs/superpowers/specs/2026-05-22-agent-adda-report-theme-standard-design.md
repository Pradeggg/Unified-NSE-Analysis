# Agent Adda Report Theme Standard Design

## Goal

All HTML and PDF reports generated by `nse_agent` should use one standard visual system based on the existing sector rotation report: compact header, market-style metric cards, summary cards, readable tables, badges, print support, and responsive layout.

## Approach

Use a shared Agent Adda report shell in `terminal/reports.py` as the first-class standard for generic generated reports. The shell will carry a stable theme marker and reusable CSS classes inspired by `reports/latest/sector_rotation.html`, including `site-hdr`, `metrics-row`, `metric-card`, `summary-card`, `tbl-wrap`, `data-table`, `mbadge`, and report badges.

The sector rotation report can remain a specialized dashboard with charts and tabs. Its current styling is the visual base, not a file to copy wholesale into every report.

## Scope

- Update the generic HTML report template in `terminal/reports.py`.
- Add sector-rotation-standard theme markers and shared component classes.
- Add standard report KPI cards for report type, subject, generated time, and output engine.
- Keep Markdown-to-HTML report rendering compatible with existing reports.
- Keep PDF generation unchanged except that it inherits the standardized HTML.
- Add tests that assert generated HTML uses the standard theme and component classes.

## Non-Goals

- Do not rewrite the bespoke sector rotation chart/tab dashboard in this pass.
- Do not change report data generation, recommendation policy, or PostgreSQL persistence.
- Do not change terminal Markdown rendering.

## Testing

Add targeted tests around `generate_report(..., output_format="html")` to verify the generated file includes the standard theme marker and common layout classes. Existing report tests should continue to pass.
