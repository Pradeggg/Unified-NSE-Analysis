# Agent Adda Codex Skill Index

This page links the Codex skills that are currently built for Agent Adda.

## Core Skills

| Skill | Use For |
|---|---|
| `agent-adda-skill-catalog` | Find the right Agent Adda skill, registry entry, or seed card |
| `agent-adda-fundamentals` | Deep company research, earnings review, valuation, and shareable reports |
| `agent-adda-market-daily` | Daily market refresh, breadth, live prices, and HTML reporting |
| `agent-adda-portfolio-review` | Add/trim/hold/exit decisions and portfolio risk review |
| `agent-adda-report-qa` | Validate reports, links, freshness, and email-ready output |
| `agent-adda-publish-intelligence-report` | Publish validated Agent Adda reports to agentadda.in and prepare/send approved notifications |
| `agent-adda-tradingview-chart` | TradingView-style charts and Cursor Canvas generation |
| `agent-adda-live-prices` | Live price refresh, watchlists, and intraday context |

## Suggested Use Order

1. Use `agent-adda-skill-catalog` when you are not sure which skill fits.
2. Use the domain skill next, such as fundamentals, market daily, portfolio, charting, or live prices.
3. Use `agent-adda-report-qa` before distributing any generated report.
4. Use `agent-adda-publish-intelligence-report` to publish to `agentadda.in`, verify live URLs, and prepare or send approved notifications.
