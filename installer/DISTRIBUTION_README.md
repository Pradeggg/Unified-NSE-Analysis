# Agent Adda — Distribution Package

You received this tarball — welcome! In ~5 minutes you'll have an NSE
market-intelligence agent running locally with PostgreSQL, intraday capture,
and an LLM backend.

## Quick start (macOS / Linux)

```bash
# 1. Verify integrity (optional but recommended)
shasum -a 256 -c agent-adda-*.sha256

# 2. Extract
tar -xzf agent-adda-*.tar.gz
cd agent-adda-*/

# 3. Install (handles system deps, venv, DB, services)
./installer/install.sh
```

The installer will:
1. Detect your OS and install missing system packages (Python 3.11+, PostgreSQL, ffmpeg) via Homebrew/apt.
2. Create `.venv/` and install all pip dependencies.
3. Launch an interactive wizard that prompts for API keys (all optional except `PG_DSN`), provisions the database, and offers to install always-on background services.
4. Run `installer/doctor.py` for a final health check.

## After install

```bash
.venv/bin/python nse_agent.py        # launch the agent REPL
make -C installer doctor              # health check anytime
make -C installer app-install         # build a clickable macOS .app
make -C installer help                # see all commands
```

## First-time data load

You have **three options** to populate the database:

### Option A — Restore a historical data seed (fastest, ~2 minutes)

If you also received `agent-adda-data-<version>.tar.gz` alongside the code tarball:

```bash
shasum -a 256 -c agent-adda-data-*.sha256       # verify integrity
./installer/restore_data_seed.sh agent-adda-data-*.tar.gz
```

This restores **all historical EOD prices, scores, breadth, and reports** in
under 2 minutes via `pg_restore`. After it finishes, run `daily_refresh.py` to
top up to today.

### Option B — Bootstrap from scratch via daily_refresh (slow but free)

```bash
.venv/bin/python daily_refresh.py     # ~5–8 minutes, pulls latest day only
```

Run this daily (or let the launchd/systemd service do it) and your history
grows organically. To backfill years of history, see `archive/load_*` scripts.

### Option C — Both

Restore the seed, then schedule `daily_refresh.py` to keep it current. This is
the recommended path.
